Hero Archive

Explore characters. Compare stats. Choose a favorite.

I built a searchable character catalog that connects a React and Vite frontend to a Node.js and Express API. Visitors can search by character name, real name, or alias; filter by publisher; and open detailed profiles with biographies, connections, and power stats.

  • Added Supabase Auth accounts and per-user favorites protected by row-level security.
  • Created a Battle mode that compares six character stats and presents the result in a cinematic matchup.
  • Handled missing character images with local artwork fallbacks and an accessible image preview.

The Orrery

A personal celestial observatory.

The Orrery calculates current planetary placements, natal signs, and major aspects in a focused dashboard. I built the React interface around Astronomy Engine and kept the astronomical calculations separate from traditional astrology interpretations.

  • Converted local birth date and time with IANA time zones, explicitly handling daylight-saving gaps and repeated clock times.
  • Saved charts and journal entries to Supabase for signed-in users, with PostgreSQL row-level security limiting each account to its own records.
  • Added browser-local journal mode for guests and an explicit, duplicate-safe import into an account.
