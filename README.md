# Rory J Richards Portfolio

This is a static portfolio site. It has no build step or server-side dependencies.

## Files

- `index.html` - portfolio page
- `Rory-Richards-Resume.pdf` - résumé download
- `assets/` - project screenshots

## Preview locally

Open `index.html` in a browser. The project demos and repository links open their hosted pages; the résumé and screenshots use paths relative to the site root.

## Publish with GitHub Pages

1. Create a repository for the portfolio on GitHub.
2. Add `index.html`, `Rory-Richards-Resume.pdf`, and the `assets` directory at the repository root.
3. In the repository settings, enable GitHub Pages and publish from the `main` branch root.
4. Open the Pages URL and confirm the screenshots, résumé download, email link, and both project links work.

The Rose/Cyan accent selector works in the browser and saves its selection locally.
